# Seguridad

Este proyecto es un analizador y no debe recibir permisos para operar fondos.
No agregues claves privadas, seed phrases ni API keys con permisos de trading o
retiro.

Si encuentras una vulnerabilidad, repórtala de forma privada al propietario del
repositorio antes de abrir un issue público. Revoca inmediatamente cualquier
secreto expuesto y elimina su historial de Git; cambiar solo el archivo no
invalida una credencial filtrada.
